## 🧠 Apa yang Saya Pelajari?

### AI Engineer

AI Engineer berfokus pada pembangunan aplikasi atau sistem yang memanfaatkan teknologi AI/ML dan mengintegrasikannya dengan software, API, database, serta deployment.

### AI Engineer vs ML Engineer vs Data Scientist

**Data Scientist**

* Fokus pada data
* Exploratory Data Analysis
* Statistik
* Insight
* Eksperimen

**ML Engineer**

* Fokus pada machine learning model
* Training
* Evaluation
* Deployment
* Monitoring

**AI Engineer**

* Fokus pada integrasi AI ke aplikasi
* API
* AI/ML model
* LLM
* Database
* Application architecture
* Deployment
